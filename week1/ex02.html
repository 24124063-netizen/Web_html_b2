How a Web Page Works

HTML - Structure

HTML organizes a page's headings, paragraphs, images, and forms; Wikipedia uses HTML to structure its readable encyclopedia articles.

CSS - Appearance

CSS controls colors, spacing, typography, and layout; the BBC News website uses styling to present its stories clearly.

JavaScript - Behavior

JavaScript makes pages interactive with menus, search, and updates; Google Maps uses it to respond when visitors explore a map.

A Framework Example

Bootstrap provides a responsive grid and reusable layout tools that help developers build pages that adapt to different screen sizes.
